# ARACHNE-
ARACHNE is a 6-legged, 12-servo walking robot built around two focused technical challenges, deliberately scoped down from an earlier multi-part design to ensure depth over breadth: coordinated multi-servo gait generation and real-time obstacle detection with behavioral response. The project uses an ESP32-S3 as the control core, a custom PCB, and a modified mechanical frame of bot having six legs and a main body.
